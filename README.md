# zoopedia
ZooPedia, hayvan türlerine ait bilgileri görsel ve kategorize içeriklerle sunan web platformudur. HTML, CSS ve JavaScript ile geliştirilen proje, veri saklama için LocalStorage kullanır. Öğrenciler ve doğaseverler başta olmak üzere sade arayüzüyle kolay kullanım sağlar. Teorik bilginin pratik uygulamaya dönüştürülmesini amaçlar.
